**Быстрый, полностью автономный и универсальный конвертер файлов для Windows.** Преобразует видео, аудио, изображения, документы Office, PDF и архивы в **1 клик прямо из контекстного меню Проводника** или через удобный графический интерфейс.

---

## ✨ Главные преимущества

* 🔒 **100% Офлайн и приватность** — ни один байт не уходит в интернет. Идеально для конфиденциальных договоров, бухгалтерии, персональных данных (152-ФЗ / GDPR).
* ⚡ **Конвертация в 1 клик** — нажимаете правой кнопкой мыши по файлу в Проводнике → «Конвертировать в» → выбираете целевой формат.
* 📦 **Никаких ограничений** — никаких лимитов на размер файла (в отличие от онлайн-сервисов с ограничениями 25–50 МБ) и никаких подписок.
* 🎛️ **Полноценный GUI-режим** — пакетная конвертация очереди файлов, выбор произвольной папки сохранения и настройка качества (High, Standard, Small).
* 🛠️ **Интеграция в Windows** — собственный быстрый графический установщик (`Setup.exe`), ярлыки в меню «Пуск» и на Рабочем столе, поддержка Windows 10 и Windows 11, корректная деинсталляция через «Параметры Windows».

## 🚀 Установка

1. Скачайте проект или [последний релиз](https://github.com/Zmeykofa/file-converter-windows/releases).
2. Запустите **`Установка Конвертера.exe`** (или `Setup.exe`).
3. Выберите нужные галочки (контекстное меню, ярлыки) и нажмите **«Установить»**.
4. Программа автоматически:
   * Разместит все модули в системную пользовательскую папку `%LOCALAPPDATA%\Programs\FileConverter`;
   * Зарегистрирует подменю Проводника;
   * Создаст ярлыки в меню «Пуск» и на Рабочем столе;
   * Пропишет запись в «Установленные приложения» Windows.

> **Тихая установка:** можно запустить установщик в фоновом режиме:
> ```cmd
> Setup.exe /silent
> ```

## 💡 Как пользоваться

### Вариант 1. Быстрая конвертация через контекстное меню (ПКМ)
1. В Проводнике Windows нажмите правой кнопкой мыши по любому файлу.
2. В Windows 11 выберите *«Показать дополнительные параметры»* (или нажмите `Shift + F10`).
3. Наведите на **«Конвертировать в»** и выберите формат (например, `В WEBP` или `В MP3`).
4. Появится аккуратный диалог с прогрессом обработки, и готовый файл сохранится рядом с исходником.

### Вариант 2. Главное окно (пакетная обработка и настройки)
* Нажмите ПКМ по файлу → **«Конвертировать…»**, либо запустите ярлык **«Конвертер файлов»** на Рабочем столе / в Пуске.
* В открывшемся окне можно:
  * Перетащить мышью (Drag & Drop) несколько файлов одной категории;
  * Выбрать нестандартную папку для сохранения результата;
  * Настроить качество медиа (*Высокое*, *Обычное*, *Меньший размер*);
  * Нажать **«Конвертировать»** и отслеживать общий прогресс очереди.

## 🛠️ Сборка из исходников

Для сборки исполняемых файлов не требуется Visual Studio — используется стандартный компилятор `csc.exe`, входящий в состав Windows (.NET Framework 4.0+):

```cmd
build.cmd
```

Скрипт собирает:
* `Converter.exe` — лаунчер основного графического интерфейса;
* `menu-launcher.exe` — фоновый лаунчер для контекстного меню;
* `Setup.exe` (`Установка Конвертера.exe`) — графический установщик;
* `Uninstall.exe` — деинсталлятор.

## 🧩 Внешние компоненты

Программа использует проверенные свободные движки, расположенные в папке `components/`:
* [FFmpeg](https://ffmpeg.org/) — работа с аудио и видео (LGPL / GPL);
* [ImageMagick](https://imagemagick.org/) — профессиональная обработка растровой графики (Apache 2.0);
* [7-Zip](https://www.7-zip.org/) — распаковка и упаковка архивов (LGPL);
* [LibreOffice](https://www.libreoffice.org/) — конвертация документов, таблиц и презентаций в headless-режиме (MPL 2.0);
* [PDFium](https://pdfium.googlesource.com/pdfium/) — быстрое извлечение текста и рендеринг страниц PDF.

Если вы клонировали репозиторий без бинарных модулей, запустите:
```powershell
powershell -ExecutionPolicy Bypass -File .\download-components.ps1
```

## 🗑️ Удаление

Удалить программу можно в любой момент:
* Через **Параметры Windows** → *Приложения* → *Установленные приложения* → *Конвертер файлов* → **Удалить**;
* Либо запустив **`Uninstall.exe`** из папки установки.

Деинсталлятор начисто удаляет пункты из контекстного меню, очищает реестр, удаляет ярлыки и стирает файлы приложения.
